═══════════════════════════════════════════════════════════════
   🎯 ¿POR DÓNDE EMPIEZO?
═══════════════════════════════════════════════════════════════

Sigue estos pasos en orden:


PASO 1: Verificar tu entorno
────────────────────────────────
Abre PowerShell en la carpeta del proyecto y ejecuta:

    .\verificar-entorno.ps1

Esto te mostrará qué tienes instalado y qué te falta.


PASO 2: Instalar lo que falta
────────────────────────────────
El proyecto requiere:

✓ Node.js (v18 o superior)
✓ PHP 8.2 o superior
✓ Composer

Si te falta alguno, consulta la guía detallada:

    GUIA_INSTALACION.md

O si prefieres un resumen rápido:

    INICIO_RAPIDO.md


PASO 3: Configurar el proyecto
────────────────────────────────
Una vez que tengas PHP y Composer instalados, ejecuta:

    .\setup-proyecto.ps1

Este script hace TODA la configuración automáticamente:
- Crea el archivo .env
- Instala todas las dependencias
- Configura la base de datos
- Compila los assets


PASO 4: Iniciar el proyecto
────────────────────────────────
Para ejecutar el proyecto:

    .\iniciar-proyecto.ps1

O directamente:

    cd GestionComunidad\gestion-comunidad
    composer dev

Luego abre tu navegador en: http://localhost:8000


═══════════════════════════════════════════════════════════════
   📋 RESUMEN TÉCNICO
═══════════════════════════════════════════════════════════════

Tecnologías del proyecto:
- Backend: Laravel 12 (PHP 8.2+)
- Base de datos: SQLite (no requiere instalación adicional)
- Frontend: Vite + Tailwind CSS + Alpine.js
- Autenticación: Laravel Breeze
